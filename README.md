# minecraft-mod-I9-23V-bespredel
Инструментальные средства разработки программного обеспечения

Название команды: Беспредел

Состав команды: Перетятько А.А., Политов Д.А., Стрюков Н.С.

Структура проекта:

`src/main/java` — исходный код мода на Java, включая класс точки входа `AllInOneTools`.

`src/main/resources` — ресурсы мода (иконка, переводы, текстуры) и конфигурация `fabric.mod.json`.
