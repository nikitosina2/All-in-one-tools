# minecraft-mod-I9-23V-bespredel
Инструментальные средства разработки программного обеспечения

Название команды: Беспредел

Состав команды: Перетятько А.А., Политов Д.А., Стрюков Н.С.

Структура проекта:

`src/main/java` — исходный код мода на Java, включая класс точки входа `AllInOneTools`.

`src/main/resources` — ресурсы мода (иконка, переводы, текстуры) и конфигурация `fabric.mod.json`.

## Игровой объект

- Имя: `multitool` (инструмент «Мультитул»)
- Идентификатор: `all-in-one-tools:multitool`
- Назначение: инструмент, который заменяет кирку, топор, лопату и меч.

## Свойства объекта

- Идентификатор: `all-in-one-tools:multitool`.
- Прочность: 1561 (как у алмазного инструмента).
- Скорость добычи: 8,0. Мультитул быстро добывает блоки, для которых используются кирка, топор и лопата.
- Урон: 7, скорость атаки 1,6 (как у алмазного меча).
- Размер стопки: 1.

## Рецепт и баланс

Мультитул создаётся в верстаке из четырёх алмазных инструментов (кирка, топор, лопата, меч) в сетке 2 × 2. На рецепт уходит 9 алмазов и 7 палок. Прочность мультитула равна прочности одного алмазного инструмента, а заменяет он четыре, поэтому предмет не получается чрезмерно прочным.

## Дополнительное поведение: сообщение о прочности

Сценарий:
1. Исходное состояние: игрок в мире, в основной руке мультитул, частично израсходованный при добыче блоков.
2. Действие игрока: нажать правую кнопку мыши (использовать предмет) в воздух.
3. Ожидаемый результат: в чате появляется одно сообщение «Прочность мультитула: X из 1561».

Условие отбора: `stack.is(ModItems.MULTITOOL)`. Другие предметы поведение не меняют.
