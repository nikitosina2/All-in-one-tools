# All in one tools

Мод для Minecraft, который добавляет «Мультитул» — один инструмент вместо кирки, лопаты, топора и меча.

## Что добавляет мод

Предмет **Мультитул** (`all-in-one-tools:multitool`):

- быстро добывает блоки, для которых обычно нужны кирка, топор и лопата;
- по правой кнопке мыши снимает кору с брёвен и создаёт тропинки на траве;
- наносит урон как алмазный меч;
- при использовании в воздух выводит в чат сообщение об оставшейся прочности.

## Совместимость

- Minecraft: 1.21.1
- Fabric Loader: 0.20.1
- Fabric API: 0.116.17+1.21.1
- Java: 21

Другие версии не проверялись, поддержка не гарантируется.

## Установка

1. Установите Minecraft Java Edition и Fabric Loader 0.20.1 для Minecraft 1.21.1. Лучше создать отдельный профиль игры.
2. Поместите в каталог `mods` Fabric API 0.116.17+1.21.1 и файл **[all-in-one-tools-1.0.0.jar]**.
3. Запустите игру с профилем Fabric. В журнале `logs/latest.log` должна быть строка «Проект загружен успешно», а предмет — доступен в творческом инвентаре и командой.

## Использование

- Получение: вкладка «Инструменты и утилиты» в творческом режиме или команда `/give @s all-in-one-tools:multitool`.
- Рецепт: в верстаке в сетке 2 × 2 — алмазные кирка и топор в верхнем ряду, лопата и меч в нижнем.
- Основные свойства: прочность 1561, урон 7, скорость атаки 1,6, размер стопки 1.
- Дополнительное поведение: ПКМ в воздух выводит сообщение «Прочность мультитула: X из 1561».
- Пример: добудьте несколько блоков мультитулом, затем нажмите ПКМ в воздух и сравните значение прочности.

## Сборка из исходников

```
.\gradlew.bat clean build
```

Готовый JAR находится в `build/libs` (файл без суффикса `-sources`). Требуется JDK 21.


## Известные ограничения


- Нет сметающего удара меча.
- Не реализованы функции мотыги.
- Прочность, скорость и урон взяты у алмазного материала.
- Работа на выделенном сервере не проверялась.
- Протестирована только версия 1.21.1.
- При ПКМ по блоку без действия топора или лопаты мог показываться дополнительный ответ предмета, так как событие использования предмета срабатывает и после блока.
